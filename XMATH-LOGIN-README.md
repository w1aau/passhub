# XtraMath login для PassHub Business

Комплект содержит только шаблон, CSS, JavaScript, изображения и шрифт.
Общие `login.php`, `public/js/landing.js` и `public/js/dist/login.js` менять
не нужно. `public/js/login-xmath.js` уже подключён в `login-xmath.twig`.

## Отдельная установка PassHub для XtraMath

1. Скопируйте файлы комплекта в те же каталоги установленного PassHub.
2. Только в установке XtraMath используйте `views/login-xmath.twig` как
   `views/login.twig` (например, при развёртывании скопируйте его под этим
   именем). `login.php` продолжит открывать `login.twig` без изменения кода.
3. В остальных установках оставьте исходный `views/login.twig`.
4. Проверьте реальный вход WWPass, QR-код, callback и переход в PassHub.

Если оба дизайна должны работать одновременно **в одной установке**,
одного JavaScript недостаточно: `login.php` выбирает `login.twig` на сервере
до выполнения JS. Тогда владельцу потребуется настройка серверного выбора
шаблона или отдельного маршрута.

Локальный предпросмотр на порту 8765 имитирует кнопки WWPass и не проверяет
реальную авторизацию.
